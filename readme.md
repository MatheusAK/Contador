\# Contador

Projeto de um contador simples, desenvolvido para praticar a criação de interfaces e a manipulação de valores por meio de ações de incremento e decremento.

## Funcionalidades

- Exibir o valor atual do contador;
- Incrementar o valor;
- Decrementar o valor;
- Reiniciar o contador, quando disponível na interface.

## Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo principal ou abra o projeto na ferramenta indicada pela tecnologia utilizada.

## Uso

Utilize os controles exibidos na tela para alterar o valor do contador e acompanhar o resultado em tempo real.

## Estrutura

O projeto está localizado na pasta `Contador` e contém os arquivos necessários para executar a aplicação.
